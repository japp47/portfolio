Fixed a sync bug that lost records

PostgreSQL hands out sequence numbers before commit. When two pushes for one account committed out of order, a device could skip a record for good.

  • One locked head row per account
  • Pushes for an account go single file
  • 1,600+ automated tests guard the path

Open 99ile.in

GOsync/push.go SQLhead.sql 1 fix 
func (s *Store) Push(ctx, acct, ch) error {
  return s.tx(ctx, func(tx pgx.Tx) error {
    head := lockHead(ctx, tx, acct) // FOR UPDATE
    for i := range ch {
      ch[i].Seq = head + int64(i) + 1
    }
    return insertAndAdvance(ctx, tx, acct, ch)
  })
